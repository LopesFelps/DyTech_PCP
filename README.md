# DyTech_PCP: Plataforma Web Integrada para Papelaria Central Parque

## Visão Geral do Projeto

O **DyTech_PCP** (Código do Projeto) é um projeto de desenvolvimento de uma **Plataforma Web Integrada** para a Papelaria Central Parque. O objetivo principal é modernizar a presença digital da empresa, otimizar a comunicação com os clientes e fornecer funcionalidades que apoiem a gestão interna de serviços e produtos.

O projeto abrange a implementação de soluções de *full-stack*, incluindo front-end com framework moderno, back-end robusto, um banco de dados relacional e a aplicação de práticas de DevOps.

## Objetivos e Funcionalidades

O objetivo geral do projeto é desenvolver uma plataforma completa que utilize as tecnologias definidas (React, Node, MySQL, etc.) para atender às necessidades do cliente.

### Funcionalidades Entregues (Escopo)

* **Página Inicial Institucional:** Interface moderna, responsiva (adaptável a dispositivos móveis e desktops) e intuitiva para apresentação da papelaria, produtos e serviços.
* **Formulário de Orçamento Personalizado:** Permite que os clientes solicitem estimativas de produtos e serviços de forma rápida e prática.
* **Área Administrativa:** Um módulo para a papelaria gerenciar e cadastrar produtos, serviços e solicitações de orçamento, com sistema de autenticação de usuários.
* **Integração com E-mail:** Envio automático das solicitações de orçamento para otimizar o fluxo de trabalho.
* **Front-end Dinâmico:** Implementação de funcionalidades como menu mobile, rolagem suave entre seções e botão "Voltar ao Topo" para melhor usabilidade.
* **Estrutura de Dados:** Utilização de um banco de dados relacional (MySQL) para armazenamento seguro e organizado de todas as informações.
* **DevOps:** Aplicação de práticas de versionamento de código (Git/GitHub), integração contínua e automação parcial de deploy.

### Não-Escopo (Itens Excluídos Desta Fase)

Os seguintes itens não fazem parte do escopo da entrega atual:

* Integração com sistemas de pagamento online ou e-commerce.
* Desenvolvimento de aplicativos móveis nativos (Android ou iOS).
* Integração com sistemas externos de ERP ou gestão empresarial.
